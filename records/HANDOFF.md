# HANDOFF

Where the last session stopped, so the next fresh chat starts from a note instead of from nothing. Newest entry at the top, directly under this header block. `/handoff` writes it; never edit or remove an older entry.

A fresh chat reads only the newest entry, as background. To point a new chat at a specific entry, name it by its time and title ("read the 2:15 PM entry, 'Restock sheet rebuild', and work its NEXT line"), never "the top entry": another chat may have written above it since.

Entry shape:

```
## YYYY-MM-DD H:MM AM/PM - <short title>
GOAL: <the ask, in the human's words>
DONE (with proof): <each item: what, where to see it, the proof>
PERCENT: <parts done> of <parts> (<n>%)
NEXT: <the one big next task>, then <up to 3 steps>
WAITS ON: <a person: who and what, with the fix or to-do number> / <technical: what>
FILES TOUCHED: <paths>
OPEN ROWS: <fix numbers>
```
