# Decisions

Every build or system change gets one decision record, written the same turn it lands, so it can be repeated or handed to someone else later.

- One file per decision: `YYYY-MM-DD-short-name.md`, copied from `templates/decision-TEMPLATE.md`.
- One line per decision in the index below, **newest at the top**.
- A record is never edited to say something different later. A change of mind is a new record that names the old one it replaces.
